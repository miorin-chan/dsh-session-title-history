# 会话标题历史

[English](README.md)

打开会话的 **⋯** 菜单，选择 **标题历史**。
弹窗显示首次命名、历次修改、写入时间，以及标题由用户手动输入还是系统生成。
点击首行当前标题旁的铅笔，在弹窗内修改会话名称。保存后，原名称进入标题历史。
点击旧标题旁的 **↗** 可把它设回当前标题。有权重命名会话时才显示这些操作。
对话中的 Agent 也能用 `session_title_history` 工具列出、编辑或设回旧标题。

适用于 DeepSeek Harness `0.2.2-rc.5` 的桌面端与 Web 端。
可在 **Session Atlas** 中启用 **会话标题历史**。
若从源码独立安装，先在检出目录运行 `npm ci` 构建插件，再在 **插件 → 添加插件** 中选择该目录。
两种方式使用同一插件行，每个 profile 选择一种即可。

只要会话日志仍保留标题事件，安装前的记录也能查看。
手动触发重新生成时，标题仍按生成方式标注。
DSH 给分叉会话自动加编号时会调用重命名接口，这条记录也会显示为「手动修改」。
